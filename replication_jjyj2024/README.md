## 运行

需要 Stata 17 及以上，以及三个外部命令：

```stata
ssc install ftools
ssc install reghdfe
ssc install estout
```

Stata 里先 `cd` 到本文件夹，再运行 `run_all.do`：

```stata
cd "<仓库位置>/replication_jjyj2024"
do code/run_all.do
```

两种用法：

- **只跑回归和出图**：从 Google Drive 下载清洗好的数据（见 [DATA.md](DATA.md)），把 `analysis_sample.dta`、`panel_monthly.dta` 放进 `data/clean/`，把 `code/run_all.do` 里的 `local clean 1` 改成 `local clean 0`，就只运行 04–07。
- **从原始数据重跑全部**：原始数据按 [DATA.md](DATA.md) 放进 `data/raw/`，`local clean 1` 不变。原始数据放在别处时，新建 `code/00_config_local.do`，在里面改 `RAW_FACTSET`、`RAW_OTHER` 两个路径（这个文件已写进 `.gitignore`，不会上传）。

表和图写到 `output/tables/`、`output/figures/`，日志写到 `output/logs/`。每个 do 文件都按当前文件夹设路径，同一个 Stata 会话里换文件夹运行也不会写错地方。

排序时相同值的先后顺序都是固定的（`sort ..., stable`），同一份原始数据重复运行，结果完全相同（已用独立的几次运行核对）。

## 数据清洗

### 01 FactSet 公司信息与换 ID

- 每家 FactSet 公司保留 2018 年 7 月 1 日有效的那个版本，没有就保留最新的版本。A 股代码取自上市代码（60/68 开头的上交所股票、00/30 开头的深交所股票）。
- 国家用地址国家，空缺时用 `home_region`；开曼、英属维尔京、百慕大等只是注册地的，记为离岸，回归前剔除。
- **换 ID 对照表。** FactSet 在公司合并、改名、重组时会注销旧 ID、启用新 ID，数据里没有新旧 ID 的对应表。不处理的话，旧 ID 的关系会在注销那个月"断裂"，变成假断裂。原文未说明是否处理。这里用两条规则把旧 ID 改写成新 ID：
  - 规则 1：旧 ID 已注销，另一个 ID 的标准化名称相同（国家相同或一方未知）或 ISIN 相同，并且注销得更晚或没有注销；一个旧 ID 只有唯一候选时才改写。共 12,852 个旧 ID。
  - 规则 2（补规则 1 的遗漏）：规则 1 在候选不唯一时整个放弃。例如沃尔玛 2019 年 2 月换了 ID（旧 10953 → 新 122334162，ISIN 都是 US9311421039），规则 1 漏掉了，这个月会多出 23 个假断裂。规则 2 只看 ISIN，候选唯一就改写，补上 159 个旧 ID。
  - 最后处理连环换 ID（新 ID 本身又被换掉）。对照表共 13,011 个旧 ID。

### 02 企业层面的数据

- **加征关税行业**：`sic_code.csv` 是美国四轮加征关税（2018-07-06、2018-08-23、2018-09-24、2019-09-01 生效）涉及的 4 位 SIC 行业，共 436 个，与论文附表 1 逐轮逐个核对过，完全一致。每个行业取首次生效的月份作为冲击时间，与论文脚注的做法一致。
- **ST**：用 CSMAR 日交易状态 `Trdsta` 判断每家 A 股企业每年有没有 ST 交易日（ST、\*ST、PT 等都算）。
- **CSMAR 公司文件**：市场类型（只留 A 股）、上市日期、证监会行业（用来剔除金融业）。
- **Worldscope**：先用 ISIN、再用 CUSIP 前 8 位把 FactSet 公司对到 Worldscope。SIC 优先用 2017 年的，没有就用最近一年的；论文只说 SIC 来自 Worldscope，没说用哪一年。2017 年的 5 项财务指标：

| 变量 | 这里的算法（Worldscope 字段号） | 论文附表 2 的定义 |
|---|---|---|
| Size | ln(总资产美元 7230 / 1000 万) | 总资产（千万美元）的自然对数 |
| Lev | (短期债务 3051 + 长期债务 3251) / 总资产 2999 | 长期债务与短期债务（含一年内到期的长期债务）之和 / 普通股股东权益 |
| ROA | Worldscope 的 ROA 字段 8326（百分数，除以 100） | (优先股股息前净收入 + 税后利息费用) / 平均总资产 |
| ATO | 营业收入 1001 / 总资产 2999 | 营业收入 / 总资产 |
| Growth | 2017 年营业收入 / 2016 年营业收入 − 1 | 当年营业收入 / 上年营业收入 − 1 |

**Lev 的分母与论文附表 2 不同。** 附表 2 写的是普通股股东权益，这里用总资产，因为按总资产算出来的分布和论文表 1 几乎一样：供应商 Lev 的均值 0.218、最大值 0.728，论文表 1 是 0.210、0.727。

**缩尾**：Lev、ROA、ATO、Growth 先在 Worldscope 全部公司的 2017 年截面上按 1%/99% 缩尾；进入回归的 10 个控制变量再在回归样本上按观测（关系对 × 月）1%/99% 缩尾。论文只说连续变量在 1% 和 99% 的水平上缩尾，没有说明在哪个样本上做。

### 03 关系对 × 月面板与回归样本

- **关系**：FactSet 的 CUSTOMER 和 SUPPLIER 两类记录，供应商和客户由哪一方报告都算。同一关系记录的前后版本相隔不超过 7 天的，合并成一段。
- 换 ID 后确定供应商和客户，只留"中国供应商 → 外国客户"。
- **月度化**：某个月里任意一天关系有效，这个月就算存在。
- **Break**：本月存在、下个月不存在（论文的定义）。Break1：t+1 期还在、t+2 期消失；Break2、Break3 依此类推（附表 3 用）。
- **回归样本**：2017 年 1 月到 2019 年 12 月（论文脚注：冲击期截止到 2019 年底）。每对企业只看 2017 年起的第一段关系，断裂之后这一对退出样本。
- **供应商**：CSMAR 确认的 A 股（沪深主板、创业板、科创板，不含 B 股）、非金融、2017 年底前上市、当年没有被 ST、有 SIC、2017 年 5 项财务指标齐全。
- **客户**：不是中国内地企业（港澳台算外国）、国家已知且不是离岸注册地、2017 年 5 项财务指标齐全。
- **Impact**：供应商所在 SIC 行业被美国加征关税，并且客户是美国企业（论文的定义）。
- **Post**：按论文的定义，关系对首次受到美国加征关税冲击的当月及以后为 1，冲击时间是供应商所在行业首次加征关税生效的月份。对照组（Impact = 0）不受冲击，Post 始终为 0，所以 Post × Impact 就等于 Post。控制变量是 Post 与两边 2017 年 5 项特征的交互项（论文式 (1)）。

### 外推：表 2 的 Post × Impact 是什么

由 `07_extrapolation.do` 生成，不是论文的内容。

**一句话：** 表 2 的 Post × Impact 不是平均企业受的冲击，而是 10 个控制变量都等于 0 的企业受的冲击。

- 回归是 Break = a·Post + Σ b·Post × X + FE，X（Size、Lev、ROA、ATO、Growth，两边各 5 个）不中心化，a 就是 X 全为 0 时的效应。
- Size = 0 是总资产 1000 万美元。处理组冲击后观测里，供应商 Size 均值 4.52（约 9 亿美元），美国客户 8.06（约 320 亿美元），0 远在样本之外。
- 两个 Size 的 b 都是负的（企业越大，冲击后断得越少），顺着直线外推到 0，a 就被抬高。打个比方：用“身高 0 厘米的人有多重”代表人群的体重。

第 (1) 列的分解（`extrapolation_decomp.csv`）：每一项从处理组均值外推到 0，给 Post × Impact 加上 −b × 均值。客户 Size 加了 0.050，客户 Lev 0.027，供应商 Size 0.021，供应商 ROA 0.014，其余 6 项合计 0.002；一共 0.114，把均值处的 −0.008 变成了 0.107。

**加固定效应挡不住外推。** 把同样的 10 个交互项在处理组冲击后的均值处中心化，模型的拟合不变，Post × Impact 就变成“X 取均值时的效应”：

| | (1) | (2) | (3) | (4) |
|---|---:|---:|---:|---:|
| 论文写法（外推到 X = 0） | 0.1067\*\*\* (0.0313) | 0.0858\*\*\* (0.0314) | 0.0628\* (0.0327) | 0.1138\*\*\* (0.0432) |
| 中心化 | −0.0076\* (0.0044) | −0.0056 (0.0045) | −0.0080\* (0.0044) | −0.0085 (0.0063) |
| 不加交互项 | −0.0090\*\* (0.0043) | −0.0070 (0.0044) | −0.0089\*\* (0.0043) | −0.0079 (0.0064) |

固定效应同表 2，按关系对聚类。四列逐列加固定效应，外推出的正效应都还在；中心化后四列都在 −0.006 到 −0.009 之间。

**事件研究也是外推的。** 附图 1 的论文式 (2) 同样控制不中心化的相对月份 × 特征，系数是 X = 0 处的效应。中心化后（`extrapolation_es.csv`、`extrapolation_event_study.png`）：

| | 冲击前 5 个系数联合为 0 的 p | 冲击后 7 个系数联合为 0 的 p |
|---|---:|---:|
| 论文写法（不中心化） | 0.506 | 0.002 |
| 中心化 | 0.085 | < 0.001 |
| 不加特征 | 0.085 | < 0.001 |

中心化后冲击前在 10% 水平上就不能通过；冲击后显著的是负系数（+2 月 −0.029），论文写法里 +4 月 0.346 的峰值消失。

### 差异的可能来源

样本规模和控制变量的分布与论文很接近，但系数仍有差别。可能的原因之一是数据版本：FactSet 的关系记录和 Worldscope 的财务数据都会回溯修订，这里用的不是论文当时下载的数据。另外，上面"原文未说明"的几处，这里的做法不一定和论文相同。
