数据清洗与 [../replication_jjyj2024](../replication_jjyj2024/)（丁浩员、董文娟、余心玎 2024 的供应链复现）完全相同，只是关系换成 FactSet 的合作关系（PARTNER）。问的是：美国加征关税之后，受冲击行业的 A 股企业与美国伙伴的合作关系，是否比对照组更容易断裂。

## 主表的写法

处理组是 A 股企业所在行业被美国加征关税（`tariff_i = 1`）且伙伴是美国企业（`us = 1`）的关系对，即 `impact = 1`；其余三格是对照组。`postimpact = post × impact`，即论文写法的 Post：只有处理组在本行业首次加征关税生效月及以后为 1。

| 列 | 回归 | 说明 |
|---|---|---|
| (1) | `reghdfe break postimpact, noabsorb` | 只有 postimpact |
| (2) | (1) + `postsize postlev postroa postato postgrowth` | 财务变量，《经济研究》的写法：postimpact × A 股企业 2017 年的 Size、Lev、ROA、ATO、Growth |
| (3) | `reghdfe break postimpact, absorb(firm_m)` | 只有 postimpact，加 A 股企业 × 月固定效应：同一家企业同一个月，美国伙伴和其他外国伙伴比 |
| (4) | (3) + `us us_post us_tariff` | 三重差分 |

四列的标准误都按 A 股企业聚类。财务变量先在回归样本上按观测 1%/99% 缩尾，再乘以 postimpact。第 (2) 列 postimpact 的系数是财务变量都等于 0 时的效应，这是论文写法本身的含义。

附图 1 按论文式 (2) 估计：相对月份 −6 到 +6、以 −1 为基期，控制相对月份 × 处理组 × A 股企业 2017 年 5 项特征，关系对固定效应和年月固定效应，按关系对聚类；相对月份只对处理组定义，与供应链复现相同。

## 运行

需要 Stata 17 及以上，以及 ftools、reghdfe、estout（`ssc install` 安装）。Stata 里先 `cd` 到本文件夹，再运行：

```stata
cd "<仓库位置>/partnership_break"
do code/run_all.do
```

- **只跑回归和出图**：从 Google Drive 下载清洗好的数据（见 [DATA.md](DATA.md)），放进 `data/clean/`，把 `code/run_all.do` 里的 `local clean 1` 改成 `local clean 0`，只运行 04–09。08 的存续率和数量、09 的伙伴财务指标还要用 full_panel 的完整面板，见 [DATA.md](DATA.md)。
- **从原始数据重跑全部**：原始数据与 replication_jjyj2024 是同一批文件，按 [DATA.md](DATA.md) 放进 `data/raw/`。放在别处时，新建 `code/00_config_local.do` 改路径（不会上传）。

表格图要在 09 之后另外运行 `python3 code/09b_tables_png.py`（只用 Python 标准库，需要 Google Chrome 截图；Chrome 不在 macOS 默认位置时设环境变量 `CHROME`），表 3 还要读 replication_jjyj2024 的 `07_extrapolation.do` 的输出。

每个 do 文件都按当前文件夹设路径，同一个 Stata 会话里换文件夹运行也不会写错地方。从原始数据完整跑一遍约一分半钟，重复运行的结果完全相同。

## 数据清洗（与供应链复现的异同）

相同的地方：换 ID 对照表（两条规则）、只剔除 ST 当年、Worldscope 2017 年 5 项指标（Lev = 债务/总资产）、加征关税行业及首次生效月；月度面板、月内任一天有效即存在、同一记录前后版本相隔 7 天以内合并；每对只看 2017 年起的第一段、样本 2017m1–2019m12；Post 只对处理组冲击后为 1；财务变量在回归样本上按观测 1%/99% 缩尾。

不同的地方：

| 地方 | 供应链复现 | 合作关系 |
|---|---|---|
| 关系 | CUSTOMER、SUPPLIER，供应商是 i、客户是 j | PARTNER，不分方向，哪一方报告都算，A 股企业那一方是 i |
| 伙伴的财务数据 | 必须齐全，两边都控制 | 不要求，只控制 A 股企业的 5 项 |
| 回归的列 | 论文表 2：四列都有控制变量，依次加固定效应，按关系对聚类 | 上面的四列，按 A 股企业聚类 |
| 分类型 | 无 | 按 FactSet 子类型分三大类，每类单独建面板 |

### 三大类

按 FactSet 子类型的字面意思分：

| 大类 | 子类型 |
|---|---|
| K 知识类 | RESCOLB 研发合作、TECHNGY 技术、LICENIN 许可引进、LICENOT 许可输出、PLICENS 专利许可、INTPROD 产品集成 |
| C 资本类 | INVESTO 投资方、EINVEST 被投资方、JVENTUR 合资 |
| M 市场类 | DISTRIB 分销、MARKTNG 营销、MANUFAC 制造 |

未注明子类型的 NA 不归类，只算在"全部合作关系"里。全库合作关系段 780,494 段，其中有 A 股企业一方的 48,921 段（C 29,762、K 15,947、M 3,196、NA 16）。每一类单独建面板：某月"存在" = 这一类至少有一段关系当月有效；断裂 = 这一类本月存在、下个月不存在，同一对企业别的类型的关系还在，也算这一类断裂。

### 三大类各自断了多少（描述统计）

上面的回归比较处理组和对照组。这一节不分处理组，看三类关系各自断了多少，由 `08_types_desc.do` 生成。存续率和数量用 [full_panel](../full_panel/) 的完整面板：清洗与本文件夹相同，不截时间、不做样本筛选，范围是 A 股企业与境外企业的全部合作关系（含港澳台，也含国家未知和只有离岸注册地的企业）。

存续率是某个月存在的关系，到后一个月这一类合作仍然存在的比例，中间断过又恢复的也算。2018m6 是第一轮加征关税生效的前一个月，前后各取 18 个月：

| | 冲击前：2016m12 → 2018m6 | 冲击后：2018m6 → 2019m12 | 2018m6 → 2024m7 |
|---|---:|---:|---:|
| 全部合作关系 | 55.4%（742 / 1,340） | 52.8%（879 / 1,665） | 26.7%（445 / 1,665） |
| K 知识类 | 39.6%（230 / 581） | 45.4%（295 / 650） | 14.2%（92 / 650） |
| C 资本类 | 65.6%（494 / 753） | 56.3%（563 / 1,000） | 32.6%（326 / 1,000） |
| M 市场类 | 50.0%（17 / 34） | 57.1%（32 / 56） | 39.3%（22 / 56） |

- K 断得最多，冲击前后都只剩四成左右。C 冲击前最稳定，但它是唯一冲击后断得更多的一类（65.6% → 56.3%）。M 只有几十个关系，比例不稳。
- 整批结束指同一家 A 股企业同一个月断掉 5 个及以上这一类关系。K 的断裂里整批结束很多：2017m1–2018m6 的 431 次里有 154 次，2018m7–2019m12 的 534 次里有 120 次。C 很少，分别是 344 次里 9 次、578 次里 50 次（`types_batch.csv`）。去掉整批结束后排序不变：K 冲击前后为 52.3%、51.4%，C 为 66.3%、58.8%，M 为 58.6%、57.1%。
- 只看满足回归样本条件的关系（筛选与 `panel_monthly.dta` 相同），排序也不变：K 40.0% → 43.3%，C 67.2% → 55.4%，M 53.8% → 58.7%。
- 净数量（新增减去断掉）：2018m6 到 2019m12，K 650 → 757，C 1,000 → 954，M 56 → 100，只有 C 净减少。K 断得多，但新增得更多。2020 年以后三类都大幅增加，到 2024m7 为 K 1,603、C 1,613、M 462。每月的数量在 `types_stock.csv`。
- 2016 年和 2020m7 以后的月份不在本文件夹的数据里，只在完整面板里有。完整面板里与本文件夹数据重合的行已逐行核对一致（full_panel 的 `check_samples.csv`）。

回归样本的月断裂率（%）如下。冲击前、后按 `post` 分：加征行业从本行业首次生效月起，其余行业从 2018m7 起。

| | 处理组：冲击前 | 处理组：冲击后 | 对照组：冲击前 | 对照组：冲击后 |
|---|---:|---:|---:|---:|
| 全部合作关系 | 2.90 | 3.52 | 2.80 | 3.73 |
| K 知识类 | 3.92 | 3.67 | 3.92 | 4.65 |
| C 资本类 | 2.09 | 3.43 | 2.10 | 3.20 |
| M 市场类 | 0.83 | 2.38 | 2.43 | 3.81 |

C 冲击后断得多，但处理组和对照组涨得差不多，所以回归里看不出处理组多断。K 的处理组冲击后反而略降。M 的处理组一共只有 10 次断裂。观测值和断裂次数在 `types_break_rate.csv`。

合起来看：K 本身断得最多，C 和 M 少；冲击后断得更多的只有 C，但处理组并没有比对照组断得更多。

### 外推：Post × Impact × X

供应链复现的表 2 里，Post × Impact 的系数是 10 个 Post × 财务变量都等于 0 时的效应：交互项不中心化，Post × Impact 就是把这些变量外推到 0 处的值。这一节看合作关系上能不能同样靠外推得到显著的 Post × Impact，不限于论文用的财务变量，正负都算。由 `09_extrapolation.do` 生成。

做法是在主表的回归里加一个 Post × Impact × X（X 不中心化），列的写法同主表，另加第 (5) 列，用论文表 2 第 (1) 列的关系对 + 月份固定效应。五列都按 A 股企业聚类。每列另报 X 取处理组冲击后均值时的效应（Post × Impact + γ × 均值）。伙伴 j 的财务指标和每段关系的起始月取自 full_panel 的完整面板。

**伙伴规模 Size_j：能做出显著的负效应。** Size_j = ln(伙伴 2017 年总资产美元 / 1000 万)，在样本上按 1%/99% 缩尾。只用伙伴有 Size_j 的观测，共 26,278 行，是主表 42,332 行的一部分。

| | (1) | (2) | (3) | (4) | (5) |
|---|---:|---:|---:|---:|---:|
| Post × Impact（Size_j = 0） | −0.0318\*\*\* (0.0070) | −0.0228 (0.0176) | −0.0081 (0.0176) | −0.0079 (0.0208) | −0.0474\*\*\* (0.0170) |
| Post × Impact × Size_j | 0.0051\*\*\* (0.0012) | 0.0042\*\*\* (0.0015) | 0.0018 (0.0031) | 0.0018 (0.0031) | 0.0084\*\*\* (0.0029) |
| Size_j 取处理组均值时 | −0.0003 (0.0043) | 0.0033 (0.0178) | 0.0033 (0.0075) | 0.0036 (0.0131) | 0.0045 (0.0097) |
| A 股企业财务变量 | 否 | 是 | 否 | 否 | 否 |
| A 股企业 × 月固定效应 | 否 | 否 | 是 | 是 | 否 |
| 关系对、月份固定效应 | 否 | 否 | 否 | 否 | 是 |
| 观测值 | 26,278 | 26,278 | 16,379 | 16,379 | 26,228 |

\*\*\* p<0.01。第 (4) 列另有 US、US × Post、US × Tariff，系数在 `extrap_grid.csv` 里不列出。

- 方向与供应链相反：伙伴越大，冲击后断得越多（γ > 0），把 Size_j 外推到 0（总资产 1000 万美元的伙伴），Post × Impact 就是负的：第 (1) 列每月少断 3.18 个百分点，第 (5) 列少断 4.74 个百分点。处理组冲击后 Size_j 的均值是 6.20，在均值处效应约为 0，不显著。
- 第 (2) 列加了 A 股企业的 5 个财务交互项后，Post × Impact 不再显著；第 (3)(4) 列加企业 × 月固定效应后也不显著。
- 这里的外推没有超出数据：处理组冲击后 Size_j 最小是 −0.14。按 Size_j 四分位分段、每段单独估（`extrap_bins.csv`），最小的四分之一（Size_j ≤ 4.46，总资产约 8.6 亿美元以下）冲击后显著少断：无固定效应 −0.0229（p < 0.001），关系对 + 月份固定效应 −0.0304（p = 0.003）。其余三段都不显著，最大的四分之一为 +0.0158（p = 0.108）、+0.0238（p = 0.309）。所以负的 Post × Impact 来自规模最小的美国伙伴，不只是线性外推的结果。
- 三大类（第 (1) 列 / 第 (5) 列）：K −0.0411\*\*\* / −0.0773\*\*\*，C −0.0222\* / −0.0240（p = 0.354），M −0.0506\*\*\* / −0.1219\*\*\*。Size_j 取处理组均值时：K −0.0159\*\*\* / −0.0113，C +0.0136\*\* / +0.0135，M −0.0050 / −0.0501\*。

**关系已存在的月数 age：只在第 (5) 列显著，分段核对不支持。** age = 当月减这一段关系的第一个月；面板从 2016m1 起，更早开始的关系按 2016m1 算，处理组冲击后的观测里有 18.0% 是这种情况。第 (5) 列 Post × Impact（age = 0，即新建立的关系）为 +0.0610（p = 0.008），γ = −0.0021（p = 0.003）；第 (1)–(4) 列为 0.0023、0.0140、−0.0073、−0.0058，都不显著。按 age 分段（0–5、6–11、12–23、24 个月及以上）单独估，0–5 个月这一段在无固定效应时为 −0.0151（p = 0.003），在第 (5) 列的固定效应下为 0.0008（p = 0.972），都不是正的。所以 +0.0610 只是关系对固定效应下线性外推的结果。

**其余调节变量都做不出显著结果。** A 股企业规模 Size_i、冲击后第几个月、ln(A 股企业的伙伴数)、ln(伙伴的 A 股企业数)、A 股企业伙伴中美国企业的比例：五列里 Post × Impact 都不显著（最小 p = 0.170），见 `extrap_grid.csv`。

**论文表 2 的写法原样套用**（`extrap_paperspec.csv`）：i、j 各 5 个财务交互项，关系对 + 月份固定效应起依次加固定效应，按关系对聚类，要求 j 的财务指标齐全。全部合作关系四列为 0.0062、0.0078、0.0448、−0.0236，都不显著（p ≥ 0.53）。K 第 (1)(2) 列为 −0.1574（p = 0.057）、−0.1531（p = 0.070）。M 四列为 0.5333、0.4920、0.4235、0.9180（p = 0.047、0.077、0.128、0.054），但只有 18 个处理组关系对，变量都取处理组均值时为 −0.0555（p = 0.015）、−0.0482（p = 0.028）、−0.0238、−0.0126，正的系数全部来自外推。

## 结论

在与供应链复现相同的数据清洗下，合作关系的 Post × Impact 在主表四列里都不显著，事件研究里冲击后没有显著为正的系数，三大类里也没有稳定的效应。描述统计上，知识类关系本身断得最多，资本类和市场类少；冲击后断得更多的只有资本类，但处理组和对照组涨得差不多。用不中心化的交互项外推，全部合作关系只有伙伴规模 Size_j 能做出显著的 Post × Impact，而且是负的：外推到很小的美国伙伴，冲击后断得更少；这个结果在加企业 × 月固定效应后消失。
